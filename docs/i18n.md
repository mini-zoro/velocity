# UI localization

Velocity ships English source text and a Simplified Chinese (`zh-Hans`)
catalog. English is the fallback and needs no catalog. Set
[`ui_language`](settings.md) to a locale tag in User preferences, choose
**Preferences > Language**, or run **Preferences: Language: …** in the command
palette. The change applies to open windows without restarting.

## Locale selection and fallback

Tags are case-insensitive BCP-47 tags. Velocity checks the requested tag, then
successively shorter parent tags, then English. For example, `zh-Hans-CN`
uses any `zh-Hans-CN` strings first, then `zh-Hans`, then `zh`, then the
English source. `zh-TW` does not select `zh-Hans`: there is no script or
region guessing. `en-GB` uses English when no more specific catalog exists.

The default, `"auto"`, walks the macOS preferred languages in order and uses the first with
an available match, including English; it defaults to English if none match.
An explicitly unavailable tag displays an unsupported-language status message
and uses English. If a catalog was removed or disabled, the preference stays in
place and can take effect again if the catalog returns.

Catalogs are read from `Packages/<package>/Localization/<tag>.sublime-localization`.
For the same tag, later translations override earlier ones in the usual
**Default < packages < User** order. Invalid layers are rejected individually.
Adding, editing, or removing one of these resources in a live profile reloads
the language inventory. Menus show native names; the palette uses the catalog's
native name in its translated caption and retains an English search alias.
In the English UI, that alias is the displayed caption. Panels, native menus
and open palette candidates refresh their prepared labels on the locale revision.

## Add a catalog

1. To test one locally, add `Packages/User/Localization/<tag>.sublime-localization`
   in a fixture profile. To ship it, add the same file under
   `crates/velocity/resources/Packages/Default/Localization/`; the build
   embeds catalogs from this tree by filename. No Rust edit or locale list is needed.
2. Use UTF-8 JSON with comments. Start with a glossary comment like the one in
   the [Simplified Chinese catalog](../crates/velocity/resources/Packages/Default/Localization/zh-Hans.sublime-localization).
   Set the native `language_name` (required) and optionally `english_name`
   for the English palette caption and search alias. Set `palette_separator`
   only if composed palette groups should use something other than `: `.
3. Map unchanged English source keys to translated values in `strings`.
   Preserve the exact set of named placeholders, including `{language}`,
   `{count}`, and `{name}` wherever they appear. You may move a placeholder
   to suit the target language. User and package catalogs can be partial;
   shipped catalogs must cover the whole UI and contain no orphan keys.

```jsonc
// Glossary: File = Datei, Save = Speichern, Language = Sprache.
{
  "language_name": "Deutsch",
  "english_name": "German",
  "strings": {
    "File": "Datei",
    "Save": "Speichern",
    "Preferences: Language: {language}": "Einstellungen: Sprache: {language}"
  }
}
```

## Test and preview

```sh
cargo test --locked --release -j 6 -p vel-i18n
cargo test --locked --release -j 6 -p velocity shipped_catalogs
```

The second command discovers every shipped catalog and checks literal
`tr`/`tr_fmt` keys, menu captions, assembled palette captions, placeholder
sets, orphans, and actual draw-list text. To inspect draw-list reports without
Metal or windows, run `--render-scenes DIR --language <tag> --audit-text`.
The layout JSON lists suspicious ASCII alongside CJK layout runs. The text
classifier excludes known data and vocabulary from the selected catalog;
review the rendered scenes as well, particularly for a Latin-script locale
whose words can overlap the English source.

```sh
profile=$(mktemp -d)
env HOME="$profile" SHELL=/bin/sh VELOCITY_LOG_DIR="$profile/logs" \
  target/release/velocity --render-scenes "$profile/scenes" --language zh-Hans \
  --scale 1,2 --only r5_find,r5_find_in_files,r5_sidebar,r25_status_selection
```

Use `--language en` for the English comparison. To preview a catalog that is
not yet shipped, add `--catalog /path/to/<tag>.sublime-localization` with the
corresponding `--language <tag>`. The render tool copies each supplied catalog
into its disposable User package; this option can be repeated for parent tags.

## Terminology

Use the platform's standard terms. Reuse nouns and verbs across menus,
palette, panels, status, dialogs, and accessibility labels. Keep captions short
and use the locale's normal punctuation. For Simplified Chinese, use
查找 / 替换 / 位置, 打开的文件 / 文件夹, 行 / 列, 空格 / 制表符宽度, and
已选择 N 个字符. Keep **保存 / 不保存 / 取消** in that order for unsaved documents.
Keep the line-ending labels **Unix**, **Windows**, and **Mac OS 9** unchanged.

Do not translate filenames, paths, project and syntax names, scopes, setting
keys, command IDs, encoding names in the status bar, theme or scheme names,
Git branch names or badges, compiler/subprocess output, or user and package
content. System-owned controls and raw diagnostics keep their original text.
